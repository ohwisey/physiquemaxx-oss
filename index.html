The tour · 02 · the real gold The 3-stage pipeline

The model never gets to pick your score.

Split the job in three. The AI describes. Plain code grades. The AI only writes it up. Same photos in, same number out.

STAGE A

See

Model · vision only

The model looks and describes. No opinions, no rating. It returns structured evidence as JSON, nothing else.

// pure observation
{ "rear_delts": {
  "visible": true,
  "separation": "low",
  "fullness": "flat" } }
STAGE B

Score

Code · temperature 0

Plain code grades that evidence against a fixed rubric. No model in this step. Deterministic. Same input maps to the same score, every run.

# fixed rubric, no LLM
score = rubric[muscle]
  .grade(evidence)
# rear_delts → A1 (weak)
# same photos → same 74
STAGE C

Narrate

Model · words only

Now the model writes the verdict, from the numbers only. It reads the score. It cannot invent one. It just says it straight.

// input = numbers, not photos
verdict(74, [
  "rear_delts: weak",
  "quads: strong" ])
// → 32 words, one action
SEE → SCORE → NARRATE
temp 0 The words can flatter. The number cannot move.
